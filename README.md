 🔐 Password Security Analyzer

A Python-based cybersecurity tool that analyzes password strength, estimates entropy, detects weak patterns, checks breach exposure using the Have I Been Pwned API, generates secure passwords, and includes a hacker-style animated GUI.

---

# ⚡ Features

 🧠 Security Analysis
- Password strength checker (Weak → Very Strong)
- Entropy calculation (password complexity score)
- Crack-time estimation
- Weak password & pattern detection

 🔐 Breach Detection
- Uses Have I Been Pwned API
- k-Anonymity model (secure checking without exposing password)

 🎲 Password Generator
- Generates strong secure passwords
- Enforces uppercase, lowercase, numbers, and symbols
- Fully randomized secure output
